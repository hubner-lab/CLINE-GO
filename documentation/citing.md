# Citing and license

## Citing CLINE-GO

A paper describing CLINE-GO is in preparation. A citation file (`CITATION.cff`) and the paper's
reference will appear here once it is out. Until then, cite the repository:
<https://github.com/hubner-lab/CLINE-GO>.

## Tutorial data

The tutorial uses the balsam poplar data of Fitzpatrick et al. (2021), which you download from
the authors' repository; please cite their paper when you use it.

- Fitzpatrick MC, Chhatre VE, Soolanayakanahally RY, Keller SR (2021). Experimental support for
  genomic prediction of climate maladaptation using the machine learning approach Gradient
  Forests. *Molecular Ecology Resources* 21: 2749–2765.
  [doi:10.1111/1755-0998.13374](https://doi.org/10.1111/1755-0998.13374)
- Data and code: <https://github.com/stephenrkeller/Fitzpatrick_etal_MER_2021>
